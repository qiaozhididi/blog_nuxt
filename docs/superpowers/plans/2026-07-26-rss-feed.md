> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 Nuxt 3 博客新增 `/rss.xml` RSS 2.0 订阅源，自动收录博客文章，支持 GitHub Pages 静态部署。

**Architecture:** 复用现有 `server/routes/sitemap.xml.ts` 模式，新建 `server/routes/rss.xml.ts` 手写 RSS 2.0 XML；通过 `nitro.prerender.routes` 预渲染为静态文件；在 `app.vue` 全局 `useHead` 加 `<link rel="alternate">` 实现自动发现。

**Tech Stack:** Nuxt 3 + @nuxt/content v3 + Nitro server routes + TypeScript strict

- 站点名：`乔治弟弟_Blog`；站点描述：`探索代码的无限可能`
- 不引入新的 npm 依赖
- TypeScript strict 模式开启（`nuxt.config.ts` 已配 `typescript.strict: true`），不允许 `any`
- Git commit message 必须用中文
- GitHub Pages 为纯静态托管，所有 server route 必须加入 `nitro.prerender.routes` 才能部署后访问
- 项目无单元测试框架，用 `npm run generate` + 文件检查 + `xmllint` 作为集成验证

## Task 1: 创建 RSS server route + 加入预渲染路由

**Files:**
- Create: `server/routes/rss.xml.ts`
- Modify: `nuxt.config.ts:13`（`routes: ['/sitemap.xml', '/blog'],` → 追加 `'/rss.xml'`）

**Interfaces:**
- Consumes: `queryCollection(event, 'blog').all()` from `@nuxt/content/server`（与 sitemap.xml.ts 同源）
- Produces: HTTP `GET /rss.xml` 返回 `application/rss+xml; charset=utf-8` 的 XML 字符串；预渲染生成 `.output/public/rss.xml`

**设计澄清（spec 自审补充）**：所有文章都输出 `<item>`；有 `date` 的输出 `<pubDate>`，无 `date` 的跳过该字段；排序时有 `date` 的按 date 倒序在前，无 `date` 的排最后；总数取前 20 篇。

- [ ] **Step 1: 创建 `server/routes/rss.xml.ts` 完整文件**

文件路径：`/Users/qzfrato/blog_nuxt/server/routes/rss.xml.ts`

完整内容：

```typescript
import { queryCollection } from '@nuxt/content/server'

// 站点级常量：与 app.vue 的 SITE_URL/SITE_NAME 保持一致
// 域名变更时需同步修改 app.vue、sitemap.xml.ts、robots.txt
const SITE_URL = 'https://qzfrato.github.io/blog_nuxt'
const SITE_NAME = '乔治弟弟_Blog'
const SITE_DESCRIPTION = '探索代码的无限可能'
const AUTHOR = '乔治弟弟'
const MAX_ITEMS = 20

// XML 转义：title/description 可能含 & < > " '
// RSS 2.0 规范要求这些字符必须转义，否则 XML 解析失败
function escapeXml(s: string): string {
  return s.replace(/[<>&'"]/g, c => ({
    '<': '&lt;',
    '>': '&gt;',
    '&': '&amp;',
    '"': '&quot;',
    "'": '&apos;'
  }[c] as string))
}

// 动态生成 rss.xml：自动收录 @nuxt/content 博客文章，
// 按 frontmatter date 倒序，最多 20 篇。新增文章无需手动维护。
export default defineEventHandler(async (event) => {
  const articles = await queryCollection(event, 'blog').all()

  // 排序：有 date 的按 date 倒序在前，无 date 的排最后
  // 取前 MAX_ITEMS 篇
  const sorted = [...articles]
    .sort((a, b) => {
      const ta = a.date ? new Date(a.date).getTime() : 0
      const tb = b.date ? new Date(b.date).getTime() : 0
      return tb - ta
    })
    .slice(0, MAX_ITEMS)

  const lastBuildDate = new Date().toUTCString()
  const selfUrl = `${SITE_URL}/rss.xml`

  const items = sorted.map(a => {
    const title = escapeXml(a.title || a.path)
    const link = `${SITE_URL}${a.path}`
    const description = escapeXml(a.description || '乔治弟弟的博客文章')
    const pubDate = a.date ? new Date(a.date).toUTCString() : ''
    return `    <item>
      <title>${title}</title>
      <link>${link}</link>
      <guid isPermaLink="true">${link}</guid>
      <description>${description}</description>${pubDate ? `\n      <pubDate>${pubDate}</pubDate>` : ''}
      <author>${AUTHOR}</author>
    </item>`
  }).join('\n')

  const xml = `<?xml version="1.0" encoding="UTF-8"?>
<rss version="2.0" xmlns:atom="http://www.w3.org/2005/Atom">
  <channel>
    <title>${escapeXml(SITE_NAME)}</title>
    <link>${SITE_URL}/</link>
    <description>${escapeXml(SITE_DESCRIPTION)}</description>
    <language>zh-CN</language>
    <lastBuildDate>${lastBuildDate}</lastBuildDate>
    <atom:link href="${selfUrl}" rel="self" type="application/rss+xml" />
${items}
  </channel>
</rss>`

  setHeader(event, 'content-type', 'application/rss+xml; charset=utf-8')
  return xml
})
```
